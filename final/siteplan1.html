Explore Kampala - Website Site Plan

Site Name

Explore Kampala

The name "Explore Kampala" was chosen because it is short, memorable, and clearly tells visitors what the website is about. It encourages both local and international tourists to discover attractions, restaurants, hotels, cultural sites, and activities around Kampala.

Optional Domain: explorekampala.ug


Site Purpose

The purpose of this website is to provide visitors with reliable travel information about Kampala. Users will be able to discover popular tourist attractions, hotels, restaurants, transportation services, shopping areas, events, and travel tips. The website will also allow visitors to contact tour guides and make travel inquiries.


Scenarios

  • What are the best tourist attractions to visit in Kampala during a weekend?
  • Where can I find affordable hotels and restaurants near Kampala city centre?

Color Schema

  • Forest Green (#2E7D32) - Used for headings, navigation, footer, and important titles.
  • Golden Yellow (#F9A825) - Used for buttons, links, and highlighted information.
  • Red (#D32F2F) - Used for call-to-action buttons and important notices.
  • Light Gray (#FAFAFA) - Used as the page background.

Testing Plan

  • Validate HTML using the W3C Markup Validator.
  • Validate CSS using the W3C CSS Validator.
  • Test responsiveness on mobile, tablet, and desktop devices.
  • Check accessibility using the WAVE Accessibility Tool.
  • Test all links, buttons, and navigation before submission.
